# Verification record and release boundaries

## Historical development evidence

The private baseline's acceptance record is dated 7 September 2026 and targets
GraphPad Prism 11.1.0 build 110218, format `1-6-1`, and MCP Python SDK 2.1.1.
It records:

- Template-based native creation, table updates, descriptive recalculation,
  selected graph styles, paired layout composition, annotations, and exports.
- An original-value change/restoration check affecting native distributions,
  summaries, and linked layouts; separate saved-output visual review.
- A protected-copy existing-label position edit/restoration through a direct
  native adapter, not a general existing-label MCP editing tool.
- A warm regeneration with preservation of an unrelated owned open document.
- A synthetic descriptive-parameter differential with independent CI endpoint
  and saved result-text checks; on-screen result rendering was not claimed.
- Seventeen negative MCP cases, plus separately identified backend script-error
  and timeout injections followed by recovery. A zero-deadline timeout injection
  does not establish behavior for every real engine hang or concurrency case.
- A historical regression result of 933 passed, 2 skipped for the larger private
  project. This is not a test count for the smaller public export.

Detailed private records and study data are not included. These statements are
maintainer summaries of existing evidence, not independently reproducible public
receipts and not new native acceptance. This release preparation does not rerun
those existing checks.

## Public export

The generic server, native adapters, synthetic seed, and selected offline tests
are exported without private development history. Study-specific importers,
clinical acceptance runners, private evidence, and GraphPad-distributed sample
archives are omitted. Read-only multiple-variable inspection remains in the
code, but vendor-example-dependent tests are not distributed.

Only `createdBy.user` and `modifiedBy.user` change in the seed's `document.json`,
replacing a local username with the public handle. Other archive members,
including opaque drawings and synthetic observations/results, are preserved.
The seed is a maintainer-created document, not an application binary or a vendor
demonstration archive.

The launcher is checkout-relative. Documentation and public packaging metadata
are rewritten. Core native-control algorithms and runtime guards are retained.
The export has not received a new native Prism runtime acceptance run.

Release-preparation checks are recorded separately after completion. They cover
the changed export inputs only and do not extend the historical native claims.
