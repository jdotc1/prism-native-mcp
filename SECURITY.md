# Security reporting

This source preview controls a local scientific application and handles data
supplied by the user. Version checks, revision guards, a shared operation lock,
and uncertain-execution quarantine are part of its design; they are not a claim
of a completed security audit.

Use GitHub's private vulnerability reporting on this repository when enabled.
If that channel is unavailable, open a public issue requesting a private contact
route without including vulnerability details or confidential material.
Do not post credentials, patient data, private documents, or unredacted logs.

Reports should identify the affected version, a synthetic reproduction, and the
observed impact. No response-time or remediation guarantee is made.
