# Prism Native MCP

Preserve Prism application integrity and original user documents. Native graphs
and statistics must remain driven by original observations and Prism's engine.
Do not patch the installed application or invent private drawing fields.

Native operations use the shared operation lock. Only the controlling parent
may operate Prism during coordinated work. Use owned disposable copies; preserve
unrelated documents and unsaved work. Never delete quarantine to bypass recovery.

Keep datasets, outputs, operation records, and local settings outside Git. Use
synthetic fixtures. Preserve version and acceptance boundaries in documentation.
Reuse accepted evidence for unchanged inputs; do not rerun checks merely because
work resumed or a handoff occurred. No publication or push without explicit
authorization.
