# Contributing

Keep contributions focused and include a synthetic reproduction where useful.
Preserve original observations and native table/graph/analysis relationships.
Do not introduce reconstructed density geometry or fixed statistical drawings.

Distinguish source tests, transport checks, native runtime acceptance, and visual
review. State the Prism version and exact scope of new native evidence. Reuse
accepted evidence when inputs have not changed; do not silently broaden claims.

Keep generated documents, operation logs, local configuration, and datasets out
of commits. Never use patient or unpublished study files as test fixtures.
Use disposable owned copies for native checks and preserve unrelated open work.

Report security-sensitive issues privately as described in [SECURITY.md](SECURITY.md).
